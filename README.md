# Service Desk Support Case Studies

This repository contains **sample source files and templates** for three independent portfolio case studies relevant to an entry-level Service Desk Administrator role.

## Projects included

1. **Application Issue Logging & Resolution Workflow** — sample ticket register, issue lifecycle, and incident-note template.
2. **Application & API Troubleshooting** — a Postman collection with a public demo API and a troubleshooting log template.
3. **SQL Database Validation & Data Consistency** — sample SQL schema, seed data, and validation queries.

> **Portfolio honesty note:** These are practice/independent case-study materials, not evidence of live client support or production service-desk employment. No real customer data is included.

## How to use

- Review and customize the ticket register with fictional sample incidents.
- Import `02-api-troubleshooting/postman_collection.json` into Postman and run the requests against the public JSONPlaceholder demo API.
- Run the SQL files in a local MySQL-compatible database, then review the validation queries.
- Replace sample outputs with your own observed results before describing the work in interviews.

## Skills demonstrated

Request logging, categorization, priority assessment, incident documentation, escalation awareness, API response inspection, issue reproduction, SQL querying, data consistency checks, and clear handoffs.
